# 04: File a repeat, a new claim, and a second source

**What to build:** A learning pass reads every enabled source before it writes, so one claim does not land twice in different words. A chat that repeats a claim already in the knowledge rewrites that card in place, still short, without appending. A chat that adds a different claim creates a new card that shares a topic with the old one. When the same lesson shows up in a second tool, that tool is added to the card's sources.
