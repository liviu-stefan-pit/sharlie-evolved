# 08: Draw the local knowledge as a graph

**What to build:** The window draws every local card, personal and work, as a graph the person can click. A node is a person, a team, a project, a source, a topic, or a card, and the links between them come from the cards in the folder. Clicking a node shows what is in it. Work cards that have been copied to the Drive folder show as synced. The view uses the Nord palette: canvas `#2e3440`, panels `#3b4252`, text `#eceff4`, ice accent `#88c0d0`, and `#a3be8c` only for the synced status.
