# sharlie-evolved

Local workspace for Sharlie. Specs, tickets, and the local-memory app live here. The app reads coding-session transcripts and writes each lesson as a markdown card kept on the machine.

## Layout

- `local-memory/` — the app (TypeScript)
- `docs/` — product notes and agent docs
- `.scratch/` — local issue tracker
- `AGENTS.md` — how agents should work in this repo

## local-memory

```bash
cd local-memory
npm install
npm test
npm run check
npm start
```
